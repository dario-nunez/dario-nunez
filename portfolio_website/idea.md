# Project goal

- portfolio website
- showcase projects to start with
- expand to blogs and other interactive content later
- work on web and mobile devices

# Proect structure

- I'm open to ideas on what the website should look like
- must be easy to navigate and intuitive

# Project style

## Idea 1

A mostly text based website that looks like a research paper. Text elements are buttons that when pressed, expand new sections. For example: "I am very proud of some projects", will have the word "projects" as a button that when pressed, expands to show the projects section, but keeping the rest of the text on the page and visible. the page would look like a 2 column document on large screens and like a single column doc on small screens like phones.
